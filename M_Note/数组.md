## 2.2 数组大小类

这是最常用的属性，指的是数组在每个方向上的元素个数

- `size`
- `length`

在 MATLAB 中，`length(A)` 的定义是：返回 `size(A)` 中**最大的那个维度长度**，即 `max(size(A))`。

- `numel`

## 2.3 数组维度

- `ndims`

其实 `ndims(A)` 返回的是 `length(size(A))`，即 `size` 结果的长度。而 MATLAB 中**所有数组都至少是二维的**（没有真正意义上的一维数组）。`linspace(1,10,10)` 生成的是一个 **1×10 的行向量**，它的 `size` 是 `[1 10]`，长度为 2，所以 `ndims` 返回 2。

## 3.2 对角数组

- `diag`

一般 `diag` 函数接收一个一维行向量数组为输入参数，将此向量的元素逐次排列在所指定的对角线上，其他位置则用 0 填充。

1. `diag(v)`：创建一个对角数组，其主对角线元素依次对应于向量 v 的元素。
2. `diag(v,k)`：创建一个对角数组，其第 k 条对角线元素对应于向量 v 的元素。
   3. 当 k 大于 0 时，表示主对角线向右上角偏离 k 个元素位置的对角线。
   4. 当 k 等于 0 时，则和 `diag(v)`一样。
   5. 当 k 小于 0 时，表示主对角线向左下角偏离 k 个元素位置的对角线。
6. diag 函数也可以接受普通二维数组形式的输入参数，此时就不是创建对角数组了，而是从已知数组中提取对角元素组成一个一维数组
   7. `diag(X)`提取二维数组 X 的主对角线元素组成一维数组。
   8. `diag(X,k)`提取二维数组X的第k条对角线元素组成的一维数组。

# 4 数组操作

## 4.1 保存和装载

## 4.2 索引

### 4.2.1 索引形式

- 双下标索引
- 单下标索引
  - 对于 m 行 n 列的数组 A，`A(x,y)` 实际上对应于 `A((y-1)*m+x)`
  - 按照列优先的顺序排列
- 逻辑索引
### 4.2.2 索引转换
+ 双下标索引->单下标索引：`subind（sz,i,j）`
+ 单下标索引->双下标索引：`ind2sub(sz,idx)`
### 4.2.3 数组扩展和裁剪
+ 变量编辑器
+ `cat` 函数
	+ `cat(dim,x,y,...)`
	+ `horzcat(x,y,...)`
	+ `vertcat(x,y,...)`
+ 块操作
	+ `repmat(A,m,n)`：把 A 整体当做一个元素，按照 m 行 n 列复制
	+ `blkdiag(A,B,...)`：把 A，B 等数组当做对角线元素创建新数组，其他元素使用 0 填充
		+ 不要求同维度
	+ `kron(A,B)`：就是把矩阵 A 中的每一个元素，都乘上整个矩阵 B，然后按照 A 的结构拼起来。
